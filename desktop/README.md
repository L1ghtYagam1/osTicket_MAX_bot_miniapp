# Provence Support — десктопное приложение

Десктоп-обёртка над веб-версией (`webapp/`, которую отдаёт backend по адресу
`https://supbot.ukprovence.ru/app`). Это **не отдельный код интерфейса** — приложение
открывает уже работающий веб-апп в собственном окне (Electron). Backend, логика и
вход через подтверждение почты — те же. Сессия (токен) сохраняется между запусками.

## Что нужно для сборки

- **Node.js 18+** (LTS) — https://nodejs.org . Нужен только на машине, где собираете `.exe`.
  У конечных пользователей Node не требуется.

## Запуск в режиме разработки

```bash
cd desktop
npm install
npm start
```

Откроется окно с приложением.

## Сборка установщика под Windows

```bash
cd desktop
npm install
npm run dist
```

Готовые файлы появятся в `desktop/dist/`:
- `Provence Support Setup x.y.z.exe` — установщик (NSIS, ярлык на рабочем столе и в меню «Пуск»);
- portable-версия `.exe`, которую можно запускать без установки.

## Сменить адрес сервера

Адрес берётся из `config.json` (рядом с приложением), пересборка не нужна:

```json
{
  "appUrl": "https://supbot.ukprovence.ru/app"
}
```

После установки файл лежит в папке ресурсов приложения; можно подменить его, чтобы
направить клиент на другой сервер (например, тестовый).

## Иконка

Положите `assets/icon.ico` (256×256) — она попадёт в окно и установщик.
Если файла нет, Electron возьмёт иконку по умолчанию (сборка всё равно пройдёт).

## Как это работает

- Окно загружает `appUrl`.
- Фронтенд ходит по относительным `/api/v1/...`, то есть к тому же домену — настраивать
  API отдельно не нужно.
- Внешние ссылки открываются в системном браузере, а не внутри окна.
- `partition: persist:provence` хранит `localStorage`/cookie → вход по почте запоминается.
